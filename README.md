## 核心模块说明

### 模块1: 宏观经济与大盘分析
- **输入**: 宏观经济数据（GDP、CPI、PMI、M2等）、指数数据（上证指数、深证成指等）
- **输出**: 大盘状态判断（牛市/震荡市/熊市）、风险等级
- **分析维度**:
  - 宏观经济指标趋势
  - 指数技术形态（均线系统、成交量、MACD）
  - 市场情绪指标（涨跌比、融资融券、北向资金）

### 模块2: 选股策略
#### 2.1 成长股策略
- **核心指标**:
  - 营收增长率 > 20%
  - 净利润增长率 > 20%
  - ROE > 15%
  - 毛利率 > 40%
  - PEG < 2
- **行业偏好**: 科技、新能源、医药、消费升级

#### 2.2 价值股策略
- **核心指标**:
  - PE < 15
  - PB < 2
  - 股息率 > 3%
  - ROE > 10%
  - 负债率 < 60%
- **行业偏好**: 金融、地产、公用事业、制造业龙头

#### 仓位配比规则
| 大盘状态 | 成长股占比 | 价值股占比 |
|---------|-----------|-----------|
| 牛市    | 60%-80%   | 20%-40%   |
| 震荡市  | 40%-60%   | 40%-60%   |
| 熊市    | 20%-40%   | 60%-80%   |

### 模块3: 观察池跟踪
- **跟踪内容**:
  - 基本面变化（财报更新、评级变动）
  - 技术面分析（关键价位、形态信号）
  - 舆情分析（新闻、研报、公告）
  - 资金流向（主力资金、北向资金）
- **更新频率**: 每日复盘

### 模块4: 交易策略输出
- **输出格式**: Markdown报告
- **包含内容**:
  - 大盘综述与风险提示
  - 持仓建议（买入/持有/减仓/空仓）
  - 目标价位与止损价位
  - 具体操作建议

## 技术实现

### 数据源
- **AkShare**: 免费开源金融数据接口库
- **覆盖**: 行情、财务、宏观数据、舆情等

### 数据存储
- **SQLite**: 轻量级关系型数据库
- **存储内容**: 历史数据、策略结果、观察池

### 编程语言
- **Python 3.8+**

### 依赖库
- akshare: 数据获取
- pandas: 数据处理
- numpy: 数值计算
- matplotlib/talib: 技术分析
- jieba: 舆情文本处理

## 使用方式

### 方式1: 手动执行
```bash
python main.py
```

### 方式2: 自动化（Hermes Cron）
```bash
# 每日收盘后执行（15:30）
hermes cron create --schedule "30 15 * * 1-5" --prompt "执行完整的股票分析流程"
```
