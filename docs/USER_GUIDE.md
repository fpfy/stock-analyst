## 系统概述

### 什么是股票分析系统？
这是一个基于Python的专业A股分析系统，提供：
- 📊 **宏观分析** - 大盘状态评估
- 🎯 **双策略选股** - 成长股+价值股策略
- 🔍 **观察池跟踪** - 持续监控股票动态
- 💡 **智能交易策略** - 基于多维度的交易建议

## 核心功能

### 1. 宏观分析
**功能**：评估当前A股市场状态

**输出**：
- 市场状态：牛市/震荡市/熊市
- 风险等级：高/中/低
- 仓位建议：成长股/价值股配置比例
- 关键信号：宏观经济指标解读

**使用方法**：
```bash
python macro_market_analyzer.py
```

### 2. 双策略选股
**功能**：基于成长和价值两个维度选股

#### 成长股策略
- 营收增长率 > 20%
- 净利润增长率 > 20%
- ROE > 15%
- 毛利率 > 40%
- PEG < 2.0

#### 价值股策略
- PE < 15
- PB < 2.0
- 股息率 > 3%
- ROE > 10%
- 负债率 < 60%

**使用方法**：
```bash
python dual_strategy_selector.py
```

### 3. 观察池跟踪
**功能**：持续跟踪选出的股票

**跟踪维度**：
- 基本面：财务数据更新
- 技术面：价格、成交量、指标变化
- 舆情：新闻、公告情感分析

**使用方法**：
```bash
python observation_pool_tracker.py
```

### 4. 交易策略
**功能**：生成具体的交易建议

**输出内容**：
- 操作建议：买入/卖出/持有
- 目标价位：基于估值和技术分析
- 止损价位：风险控制
- 仓位建议：基于波动率和风险等级

**使用方法**：
```bash
python comprehensive_trading_strategy.py
```

## 常见问题

### Q1: 如何获取Tushare Token？
**A**: 
1. 访问 https://tushare.pro/
2. 注册账号
3. 在个人中心获取Token
4. 将Token配置到.env文件

### Q2: 数据更新频率？
**A**: 
- 财务数据：每季度更新
- 行情数据：每日收盘后更新
- 宏观数据：每月更新

### Q3: 如何调整选股参数？
**A**: 编辑config.py文件，修改策略参数：
```python
# 成长股策略参数
GROWTH_STRATEGY = {
    "revenue_growth_min": 20,  # 调整营收增长率阈值
    "profit_growth_min": 20,   # 调整净利润增长率阈值
    # ...
}
```

### Q4: 系统支持哪些数据源？
**A**: 
- 主要：Tushare Pro
- 备用：AkShare
- 支持扩展其他数据源

### Q5: 如何备份数据？
**A**: 
```bash
./backup.sh
```
备份文件保存在backups/目录
