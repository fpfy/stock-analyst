### ⚙️ 使用指南

#### **1. 基础使用**
```python
from api_frequency_control import api_limiter, batch_processor, safe_api_call

# 为函数添加限流
@api_limiter(max_calls_per_minute=30, max_calls_per_hour=200)
def ai_analysis(stock_data):
    return analyze_stock(stock_data)

# 批量处理
results = batch_processor(stock_list, ai_analysis, batch_size=10)

# 安全API调用
result = safe_api_call(api_function, data, max_retries=3)
```
